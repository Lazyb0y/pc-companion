# Security policy

## Supported versions

Security fixes go into the latest release only. A vulnerability in it is fixed in a new release, as a hotfix when it can't wait, and older releases aren't updated. To get the fix, install the latest version from [Releases](https://github.com/Lazyb0y/pc-companion/releases); unless you turned off **Check for updates**, PC Companion tells you when one is out.

## Reporting a vulnerability

Don't report security vulnerabilities in public issues, discussions or pull requests. Report them privately through GitHub instead: [Report a vulnerability](https://github.com/Lazyb0y/pc-companion/security/advisories/new).

Include as much as you can:

- What the problem is and its possible impact
- Steps to reproduce, or a proof of concept
- The affected version or commit
- Your Windows version and architecture

## What happens next

- You'll get a reply in the private advisory, where the fix is discussed and coordinated.
- Once a fix is available, the advisory is published, with credit to you if you want it.
- Keep the details private until the advisory is published.
