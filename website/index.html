Useful features from macOS and Linux, on Windows

PC Companion is a free app that brings useful features from macOS, Linux, KDE Plasma and GNOME to Windows. It's one app: turn on the features you want and leave the rest off.

Download for Windows See the source code

For Windows 11, and Windows 10 version 2004 or later, on x64 and ARM64 PCs.

Features

Each feature is off until you turn it on in the settings app, and its changes apply right away.

Input & Triggers

Hot Corners

Move the pointer into a corner of the screen to run an action. Inspired by Hot Corners in macOS, the Activities corner in GNOME and screen edges in KDE Plasma.

  • Show Task View or the desktop, open Start, Search or Notifications, lock the PC, turn off the displays, start the screen saver, or run a program.
  • Keep displays on holds off the screen saver and the display timeout while the pointer rests in its corner.
  • A short delay, and optionally a key to hold, so corners don't trigger by accident.
  • Corners stay quiet while you drag a window into them, while a game or virtual machine holds the pointer, and while an app is full screen on that display.
  • Turn corners off while apps you choose are in front, and see on the page why a corner did or didn't trigger.

Input & Triggers

Lock Keys

See a short notice on screen when Caps Lock, Num Lock or Scroll Lock turns on or off, such as "Caps Lock on", on the display you're typing on. Inspired by the lock key notices of KDE Plasma and ChromeOS, and by the Caps Lock indicator of macOS.

  • Choose the keys, whether a key turning off shows too, where the notice shows and for how long.
  • Keep showing while Caps Lock is on keeps a small badge on screen that follows the window in front.
  • Stays out of full-screen apps, follows the display's scale, your light or dark mode and high contrast, and never takes the focus.
  • No keyboard hook: PC Companion reads only whether the keys are on, never the keys you type.

Input & Triggers

Input Language per App

The keyboard language switches by itself for the app in front, such as German in your browser and English in PowerShell. Inspired by the keyboard layout policies of KDE Plasma and the per-app input source tools of macOS.

  • Give the apps you choose an input method from your language list.
  • Every other app gets back the language it had when you left it, also after a restart. Or leave them the language in use, or give them all one language.
  • It switches only when an app comes to the front, so a language you choose by hand stays until you leave the app.
  • A short notice shows the new language. PC Companion never adds input methods or changes Windows' language settings.

Window Management

App Windows

Press Alt and the key above Tab to switch between the windows of the app in front, such as your File Explorer windows. Inspired by Command + ` in macOS and the same shortcut in GNOME and KDE Plasma.

  • Each press brings the app's next window to the front. Add Shift to go the other way.
  • It goes by the key's position, so it's the key above Tab on any keyboard: ` on US English, ^ on German and ² on French keyboards.
  • Use the Windows key instead of Alt if you prefer, and choose whether minimized windows count.
  • No keyboard hook: Windows tells PC Companion only when you press the shortcut.

Window Management

Minimize to Tray

Send any app's window to an icon in the notification area instead of the taskbar, and bring it back from there. Inspired by tools for Linux desktops that dock any window in the tray, and by Hide in macOS.

  • Press Windows + Shift + Z, or hold Shift as you select a window's Minimize button.
  • List apps whose windows go to the tray whenever they're minimized, such as Task Manager or a chat app.
  • Each app gets one icon: select it to bring back the window, or open its menu to choose a window or bring them all back.
  • No window is lost: turning the feature off, exiting, signing out and a crash bring every window back to the taskbar.

Window Management

Hide Apps

Put away every window of the app in front, or of every other app, with one shortcut, and bring them back as they were. Inspired by Hide, Hide Others and Show All in macOS.

  • Windows + Ctrl + H hides the app in front, such as every File Explorer window.
  • Windows + Ctrl + Shift + H hides every other app, optionally only on the display in front. Press it again to bring them back.
  • When one window comes back, the app's other windows come with it, in their order. Show all hidden windows in the PC Companion icon's menu brings back everything.
  • Windows are only minimized, so they keep their taskbar buttons and none is lost if PC Companion closes.

Window Management

Drop-down Apps

Press a shortcut to slide a chosen app's window down from the top of the screen, and again to slide it back up out of the way, as drop-down terminals do, for any app. Inspired by Yakuake and the i3 scratchpad.

  • Give each app its own shortcut: Windows + Ctrl or Alt with the key above Tab, or Windows + Ctrl + Alt + 1 to 9.
  • Choose the display, the width and height, the slide, whether the window hides when another app comes to the front, and whether it stays on top.
  • When the app isn't running, the shortcut starts it. A window on another virtual desktop comes to the one you're on.
  • The window you were using gets the focus back, and hidden windows come back on the taskbar when the feature stops or PC Companion exits.

Window Management

Title Bar Actions

Middle-click a window's title bar to minimize it or send it to the back, or turn the wheel there to make it see-through, in any app. Inspired by the title-bar actions of KDE Plasma, GNOME, Xfce and Cinnamon.

  • Middle-click, Shift + middle-click and Ctrl + middle-click can each minimize the window, send it to the back, send it to the tray or hide its app.
  • The wheel, or Ctrl + wheel, changes the window's opacity in 10% steps, from 20% to 100%.
  • Only the title bar counts, so tabs and buttons keep their clicks, and apps that draw their own title bars, such as Edge and File Explorer, work too. Apps you list, such as Firefox, keep all their title-bar clicks.
  • No window stays see-through: exiting, turning the feature off and a crash make every window opaque again.

Window Management

End App

Press Ctrl + Alt + Esc, click the window of an app that stopped responding, confirm, and PC Companion ends that app. Inspired by Ctrl + Alt + Esc in KDE Plasma and Force Quit in macOS.

  • Or choose End an app… in the PC Companion icon's menu. A red frame shows the app under the pointer, and Tab moves it through the windows on the taskbar.
  • The question names the app and how many processes end. For an app that still responds, Cancel is the default, with a note to close it as usual.
  • Ends the app with its helper processes, such as a browser's, and leaves other copies of the program running.
  • Never ends PC Companion, File Explorer or Windows' own programs, and offers Open Task Manager instead.

Desktop

System Meters

See how busy your PC is, with live CPU, memory and network use on the taskbar. Inspired by iStat Menus in macOS and the system monitor widgets of KDE Plasma.

  • The meters share one item in the taskbar's free space, next to the Widgets entry or the notification area, in three layouts, with color icons, one-color icons or none.
  • Or each meter gets its own icon in the notification area, which you can reach with the keyboard.
  • The values Task Manager shows: how busy the processor is, how much memory is in use, and how fast the PC receives and sends data. Select the meters to open Task Manager.
  • Reads only figures for the whole PC, never what each app uses or the names on the taskbar, and pauses while the PC is locked or the displays are off.

Desktop

Dynamic Wallpaper

Change the desktop picture with the time of day: at sunrise and sunset, at times you choose, or with the Windows mode, light or dark. Inspired by the dynamic desktop of macOS, GNOME's timed and light-and-dark wallpapers and KDE Plasma's day and night wallpapers.

  • Sunrise and sunset are worked out on your PC, from your time zone, or from coordinates you type or fill in once with Use my location.
  • Each part of the day gets a picture, or a folder whose pictures each show once, in a shuffled order. Each display can have pictures of its own.
  • Windows shows and fits the pictures as it does yours, and your own background comes back when you turn the feature off.
  • Steps aside when something else changes the background, until you select Resume.

Clipboard & Text

Clipboard Actions

Press Windows + Alt + V to see actions for the text you copied, such as opening a copied link or looking up a parcel number on the carrier's website. Inspired by the actions of Klipper, the KDE Plasma clipboard tool, and the actions Windows 11 once suggested for copied phone numbers and dates.

  • The menu opens at the text cursor and starts with the copied text, so you see what the action gets.
  • Make your own rules: a pattern the copied text matches, and a web address to open with the text in it, or a program to run with it.
  • Open in browser for a copied web link, with no rule needed.
  • Selected text: Windows + Alt + S shows the same actions for the text you selected, without copying it.
  • Reads the clipboard or the selection only when you press the shortcut, never from a password box, leaves alone what password managers mark private, and never keeps or sends the text.

Clipboard & Text

Middle-Click Paste

Select text in any app, then middle-click in a text box: the text goes in where the pointer is, without the clipboard. Inspired by the middle-click paste of Linux desktops, such as GNOME and KDE Plasma.

  • The clipboard is never read or changed, so what you copied stays there, and clipboard history never sees the text.
  • Only a middle-click on a text box pastes, so links, tabs, scrolling and title bars keep their middle-click. Apps you list keep all of theirs.
  • One Ctrl + Z takes a paste out, and when nothing can be pasted, a short notice at the pointer says why.
  • Reads the selection only at the middle-click, never from a password box, and leaves terminals alone.

Network

Network Profiles

Save your proxy settings as profiles, such as Office and Home, and switch between them from the PC Companion icon's menu. Inspired by network locations in macOS and by NetworkManager and the proxy settings of KDE Plasma and GNOME.

  • A profile holds the settings of Windows' Proxy page: automatic detection, a setup script, and a proxy server with its exceptions.
  • The menu marks the profile Windows uses now, also after you change the settings in Windows Settings.
  • Browsers and other apps that follow Windows' proxy settings switch with it.
  • Needs no admin rights, and never changes the settings on its own.

Files

Folder Rules

Keep folders such as Downloads tidy: rules move, copy, rename or sort files as they arrive, or move them to the Recycle Bin. Inspired by Folder Actions in macOS and by folder automation on Linux.

  • A rule matches a file's name, type, size and date, and the site it was downloaded from.
  • Destinations and new names can use parts of the file, such as Invoices\{year} or {date} {name}.
  • See the files a rule would act on while you edit it, run it on the files already there, and undo what it did from the history.
  • Never replaces a file or deletes one for good, and waits until a download has finished.

Files

Drive Actions

Do something useful when a drive is connected: import a camera card's photos into Pictures, sorted by month, back up folders to a USB drive, or open a folder. Inspired by device actions in Linux desktops and by backups that start when the backup drive is connected, in macOS and Linux.

  • Give each drive you add its own actions, and Camera cards covers any card with a camera's photos. Ask first with a notification or act at once, and eject the drive when done.
  • An import copies each photo once and never deletes anything from the card. Undo sends its copies to the Recycle Bin.
  • A backup copies new and changed files, and never deletes anything on the drive.
  • A drive is recognized by an ID that PC Companion writes on it and by its serial numbers, never by its name, and nothing on a drive is ever run.

Display

Display Profiles

Save display setups as profiles, such as Desk, TV and Presenting, and switch between them from the PC Companion icon's menu. Inspired by KDE Plasma and GNOME, which ask before keeping a display change, and by autorandr on Linux.

  • A profile sets which displays are on, the main display, the arrangement, and each display's resolution, refresh rate, orientation and HDR.
  • Make profiles from the setup you're using, so each one is a setup Windows accepted.
  • After a switch that could leave a display black, PC Companion asks whether to keep it, and goes back after 15 seconds without an answer.
  • Recognizes displays by their model and serial number, across restarts, driver updates and cable changes, and needs no admin rights.

General

Made to fit Windows

The settings app is laid out like Windows Settings, follows your light or dark mode, and works with the keyboard and screen readers.

  • Always run as administrator lets features work in front of apps that run as administrator, when PC Companion is installed for all users.
  • Update check: once a day, PC Companion tells you when a newer version is out, with a dot on its icon until you look. Check now, or turn it off.
  • Choose the language and theme, start with Windows, and open the logs when you report a problem.

Private by design

  • No data collected

    No telemetry, analytics, ads or accounts. PC Companion uploads nothing.

  • Stays on your PC

    Your settings, logs and the features' history, such as Folder Rules' undo list, are kept in %LOCALAPPDATA%\PCCompanion. Logs leave your PC only if you share them.

  • One connection

    Once a day, the update check asks GitHub for the latest release. The request is the same for everyone, and you can turn it off.

  • Open source

    All the code is on GitHub under the MIT License. Each installer has a build attestation that shows GitHub built it from this code.

Download and install

  1. Download

    Open the latest release and download the x64 installer, PCCompanion-<version>-x64.msi. PCs with an Arm processor, such as a Snapdragon, need the ARM64 one: Settings > System > About shows which under System type.

  2. Install

    Run it and select Install. PC Companion installs just for you, without admin rights. Advanced installs it for all users, which Always run as administrator needs.

  3. If Windows warns you

    The installers aren't signed yet, so Windows SmartScreen may say it doesn't recognize the app: select More info, then Run anyway. The release notes show how to check that your download is the one published.

  4. Turn on features

    Open PC Companion from Start and turn on the features you want.

Smart App Control: because the installers aren't signed yet, Windows 11 blocks PC Companion from starting while Smart App Control is on.

A newer version installs over the old one and keeps your settings. To uninstall, remove PC Companion in Settings > Apps > Installed apps.
