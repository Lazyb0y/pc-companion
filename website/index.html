Useful features from macOS and Linux, on Windows

PC Companion is a free app that brings useful features from macOS, Linux, KDE Plasma and GNOME to Windows. It's one app: turn on the features you want and leave the rest off.

Download for Windows See the source code

For Windows 11, and Windows 10 version 2004 or later, on x64 and ARM64 PCs.

Features

Each feature is off until you turn it on in the settings app, and its changes apply right away.

Input & Triggers

Hot Corners

Move the pointer into a corner of the screen to run an action. Inspired by Hot Corners in macOS, the Activities corner in GNOME and screen edges in KDE Plasma.

  • Show Task View or the desktop, open Start, Search or Notifications, lock the PC, turn off the displays, start the screen saver, or run a program.
  • Keep displays on holds off the screen saver and the display timeout while the pointer rests in its corner.
  • A short delay, and optionally a key to hold, so corners don't trigger by accident.
  • Corners stay quiet while you drag a window into them, and while a game, video or presentation is full screen.

Window Management

App Windows

Press Alt and the key above Tab to switch between the windows of the app in front, such as your File Explorer windows. Inspired by Command + ` in macOS and the same shortcut in GNOME and KDE Plasma.

  • Each press brings the app's next window to the front. Add Shift to go the other way.
  • It goes by the key's position, so it's the key above Tab on any keyboard: ` on US English, ^ on German and ² on French keyboards.
  • Use the Windows key instead of Alt if you prefer, and choose whether minimized windows count.
  • No keyboard hook: Windows tells PC Companion only when you press the shortcut.

Desktop

System Meters

See how busy your PC is, with live CPU, memory and network use on the taskbar. Inspired by iStat Menus in macOS and the system monitor widgets of KDE Plasma.

  • The meters share one item in the taskbar's free space, next to the Widgets entry or the notification area, in three layouts, with color icons, one-color icons or none.
  • Or each meter gets its own icon in the notification area, which you can reach with the keyboard.
  • The values Task Manager shows: how busy the processor is, how much memory is in use, and how fast the PC receives and sends data. Select the meters to open Task Manager.
  • Reads only figures for the whole PC, never what each app uses or the names on the taskbar, and pauses while the PC is locked or the displays are off.

General

Made to fit Windows

The settings app is laid out like Windows Settings, follows your light or dark mode, and works with the keyboard and screen readers.

  • Always run as administrator lets features work in front of apps that run as administrator, when PC Companion is installed for all users.
  • Update check: once a day, PC Companion tells you when a newer version is out. You can turn it off.
  • Choose the language and theme, start with Windows, and open the logs when you report a problem.

Private by design

  • No data collected

    No telemetry, analytics, ads or accounts. PC Companion uploads nothing.

  • Stays on your PC

    Your settings and logs are kept in %LOCALAPPDATA%\PCCompanion. Logs leave your PC only if you share them.

  • One connection

    Once a day, the update check asks GitHub for the latest release. The request is the same for everyone, and you can turn it off.

  • Open source

    All the code is on GitHub under the MIT License. Each installer has a build attestation that shows GitHub built it from this code.

Download and install

  1. Download

    Open the latest release and download the x64 installer, PCCompanion-<version>-x64.msi. PCs with an Arm processor, such as a Snapdragon, need the ARM64 one: Settings > System > About shows which under System type.

  2. Install

    Run it and select Install. PC Companion installs just for you, without admin rights. Advanced installs it for all users, which Always run as administrator needs.

  3. If Windows warns you

    The installers aren't signed yet, so Windows SmartScreen may say it doesn't recognize the app: select More info, then Run anyway. The release notes show how to check that your download is the one published.

  4. Turn on features

    Open PC Companion from Start and turn on the features you want.

Smart App Control: because the installers aren't signed yet, Windows 11 blocks PC Companion from starting while Smart App Control is on.

A newer version installs over the old one and keeps your settings. To uninstall, remove PC Companion in Settings > Apps > Installed apps.
